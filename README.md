# ぼくの・わたしのえほん 📖

## アプリURL

https://my-ehon.onrender.com/

※ Renderの無料プランを利用しているため、アクセス時に起動まで時間がかかる場合があります。

---

## 1. サービス概要

僕が、私が、物語の主人公。

お子様が自分やお友達の名前を入力するだけで、
世界にひとつだけのオリジナル絵本を作れるWebアプリです。

---

## 2. 開発背景

「せんたいヒーローになりたい」「お姫様になりたい」——
子どもたちには、自分が物語の主人公になってみたいという想いがあります。

しかし、一般的な絵本では主人公が決まっているため、
子ども自身が主人公になる体験を手軽に作ることはできません。

「自分が主人公になれる絵本があったら、子どもはどれだけ喜ぶだろう」
という想いが、このアプリのスタート地点になりました。

---

## 3. 解決したい課題

子どもが「ヒーローやヒロインになりたい」と思っても、
それを手軽に物語として実現する手段が少ないことです。

### 3-1. なぜ、この課題が起きているのか

- 既製品の絵本は主人公が固定されていて、わが子を主役にできない
- 名前入り絵本は価格が高いものや、完成まで時間がかかるものがある
- 親御さんが、子どもに「自分が主役になる特別な体験」を手軽に提供しにくい

**→ 本当に解決したい課題：親御さんが手軽に、子どもが主役の特別な物語体験を作れる場所がない**

---

## 4. 想定ユーザー

### 年齢設定

- **対象：** 4〜8歳の子どもと、その保護者
- **理由：** 文字や物語への興味が広がり始める時期で、保護者と一緒に楽しむことで親子のコミュニケーションにもつながるため

### 利用する場面

- おやすみ前の読み聞かせの時間
- 子どもと過ごすちょっとした隙間時間
- 子どもが「おはなしを読んで」と言ったとき

スマートフォン・タブレット・PCのブラウザから利用でき、
インストールや会員登録をせずに物語を作れます。

### 自分とユーザーの距離

**→ 身近な誰か（子どもを持つ親御さん）**

小売業で長年お客様と接してきた経験から、子育て世代のお客様と話す機会が多くありました。
そのなかで「子どもと過ごす時間をもっと豊かにしたい」という想いに触れてきた原体験があります。

### 実際に使われるまでのイメージ

1. SNSやQRコードからアプリを知る
2. 会員登録なしで、すぐに物語を作る
3. 子どもが自分の登場する物語を楽しむ
4. 「また作りたい」と思ったときに繰り返し利用する
5. 「みんなのものがたり」から、ほかの物語も楽しむ

## 5. 既存サービス・競合調査

### 5-1. 似たサービスとの違い

| サービスの種類 | できること | このアプリとの違い |
| --- | --- | --- |
| 名前入り絵本サービス | 子どもの名前が登場する絵本を印刷・製本できる | 注文や配送を待たず、ブラウザ上ですぐに作成できる |
| 電子絵本サービス | スマートフォンやタブレットで既存の絵本を読める | 用意された作品を読むことが中心で、入力した名前から物語を作るものではない |
| AI物語生成サービス | 入力した内容をもとにAIが物語を生成する | このアプリは生成AIを使わず、対象年齢に合わせて用意したテンプレートから物語を作る |

### 5-2. それでも自分が作りたい理由

このアプリで届けたいのは、物語を読むことだけではありません。

自分やお友達の名前が物語に登場し、
子ども自身が主人公になれる体験を、迷わず手軽に楽しめる形で届けたいと考えました。

### 5-3. 差別化を一文で表す

**「わが子が主役のオリジナル絵本を、ブラウザですぐに作って楽しめる」**

これが、このアプリで提供したい価値です。

## 6. このサービスで提供したい価値

- **行動の変化：** 毎晩の読み聞かせに「わが子が主人公の物語」という選択肢が増える
- **気持ちの変化：** 子どもが「自分が主役！」という特別感を味わえる
- **考え方の変化：** 物語を「受け取るもの」だけでなく、親子で「一緒に作るもの」として楽しめる

## 7. このアプリで実現すること

### MVPで作る機能（実装済み）

- ジャンル選択（15種類）
- 主人公・なかま・てき・キーアイテムの入力
- テンプレートを使った物語作成
- ジャンル内のテンプレートをランダムで選択
- 絵本風のページめくり表示（表紙・起承転結・裏表紙）
- ジャンルごとの挿絵表示
- みんなのものがたり一覧
- いいね機能
- 利用規約・プライバシーポリシー

### 今後追加したい機能

- ユーザー登録・ログイン機能（自分の物語を保存・管理）
- 物語のシェア機能（SNS・画像保存）
- 各ジャンルのテンプレートを5話以上に増やし、物語のバリエーションを広げる
- 管理者画面（テンプレート・ジャンルの追加・編集）
- 入力内容のバリデーションと禁止ワードフィルター

### 収益化について

現時点では未定です。

今後、次のような機能を追加する場合は、有料プランとしての提供を検討しています。

1. 現在の起承転結4ページよりも長い、10〜15ページ程度の物語作成
2. 生成AIを利用した物語作成や画像生成

生成AIを利用する場合はAPI利用料が発生するため、利用規模に合わせて料金を検討します。

## 8. このアプリの懸念点とその対策

### 懸念点①：不適切な内容の投稿

- **何が問題になりそうか：** ログイン不要のため、不適切な内容が入力・投稿される可能性がある
- **なぜそう思うか：** 子ども向けサービスであるため、不適切な投稿が表示されると安心して利用できない
- **対策：** 文字数制限などのサーバー側バリデーションと禁止ワードフィルターを実装する。将来的にはログイン機能を追加し、投稿者を管理できるようにする

### 懸念点②：物語の使い回し感

- **何が問題になりそうか：** テンプレートが少ないと「同じ物語ばかり」と感じられ、飽きられる可能性がある
- **なぜそう思うか：** 現在はジャンルごとのテンプレート数が少なく、物語の展開が限られている
- **対策：** 各ジャンルのテンプレートを5話以上に増やし、「たのしい」「しんけん」「おわらい」など、展開を選べる機能を追加する

### 懸念点③：ローカル環境と本番環境のDBの違い

- **何が問題になりそうか：** ローカルではMySQL、本番ではPostgreSQLを使用しているため、DBごとの仕様差によって本番だけで不具合が起きる可能性がある
- **対策：** Eloquentとマイグレーションを中心に実装し、DB固有のSQLを避ける。将来的にはローカル環境もPostgreSQLへ統一することを検討する

## 10. ものがたり生成の仕組み

このアプリでは、生成AIではなく、あらかじめ用意したテンプレートを使って物語を作成しています。

1. ユーザーがフォームに入力する（しゅじんこう・なかま・てき・アイテム・ジャンル）

   [![入力画面](https://i.gyazo.com/37b4838d4d1c7262ebda810c68478836.png)](https://gyazo.com/37b4838d4d1c7262ebda810c68478836)

2. 選択されたジャンルに登録されているテンプレートを、DBからランダムで1件取得する

3. `str_replace`を使い、テンプレート内のプレースホルダーを入力値に置き換える

   ```text
   {主人公} → こうたくん
   {なかま} → うさぎさん
   {てき} → おに
   {きーあいてむ} → でんせつの剣
   ```

4. 作成した物語を、絵本風のページめくり画面で表示する

   [![物語表示画面](https://i.gyazo.com/e60c6014097e8ba85717d724057c76d3.png)](https://gyazo.com/e60c6014097e8ba85717d724057c76d3)
